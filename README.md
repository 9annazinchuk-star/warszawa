# Переїзди у Варшаві — безкоштовний пошук адрес

Готова production-збірка. Адресні підказки використовують Photon та дані OpenStreetMap, а відстань і маршрут — OSRM. API-ключ і банківська картка не потрібні.

Карта працює без WebGL: використовує звичайні тайли OpenStreetMap, тому сумісна з Safari на iPhone. Анонімний ідентифікатор відвідувача зберігається у цьому браузері, щоб повторні відкриття і нові вкладки не рахувалися як нові люди.

## Запуск на Render

1. Розпакуйте ZIP і завантажте весь його вміст у корінь GitHub-репозиторію.
2. У Render встановіть Build Command: `npm install`.
3. Встановіть Start Command: `npm start`.
4. Додайте `PUBLIC_BASE_URL` з адресою вашого сайту, наприклад `https://warszawa-ho18.onrender.com`.
5. Натисніть **Manual Deploy → Clear build cache & deploy**.

Після деплою пошук адрес і підрахунок кілометрів працюють без додаткових змінних. Використовуються публічні сервіси Photon та OSRM, тому для великого навантаження вони не мають гарантії безперервної роботи.
