# Переїзди у Варшаві — готова збірка для Render

Це компактна production-збірка. Пошук адрес працює через Photon/OpenStreetMap, а відстань і орієнтовний час маршруту — через OSRM. Інтерактивну карту прибрано. API-ключ і банківська картка не потрібні.

## Що оновлено

- Клієнт обирає 1, 2, 3 або більше годин.
- Початкова ціна години — 120 zł; вона додається до маршруту та інших доплат.
- Ціну години можна змінити в **Адмін → Налаштування → Ціни**.
- Адмінкабінет адаптований для телефону: нижнє меню має заявки, статистику, налаштування і вихід.
- Мобільні модальні вікна, кнопки, фільтри та налаштування не виходять за межі екрана.
- Підпис форми: «Заявка за 1 хвилину».
- Після відправлення показується коротке повідомлення без номера заявки.
- Замість карти показуються тільки кілометри, орієнтовний час і напис «Маршрут орієнтовний».
- Головне фото зміщено так, щоб панораму Варшави було краще видно.
- Після успішного відправлення одразу відкривається помітне вікно з подякою та кнопкою «Закрити».
- Поле тривалості має зрозумілий підпис «Оберіть орієнтовну тривалість переїзду».
- Для 1, 2 і 3 годин додається погодинна ставка; для «Більше» час і вартість узгоджуються індивідуально без погодинної доплати в автоматичному розрахунку.
- У кожній заявці в адмінкабінеті є кнопка «Прокласти маршрут у Google Maps» з уже заповненими точками завантаження та доставки.

## Оновлення чинного GitHub-репозиторію

Видаліть старі файли в корені репозиторію та завантажте **весь вміст цього архіву**. Не завантажуйте саму зовнішню папку — `package.json`, `start.mjs`, `server.mjs` і `render.yaml` мають бути в корені репозиторію.

Після завантаження в Render натисніть **Manual Deploy → Clear build cache & deploy**.

Налаштування Render:

- Build Command: `npm install`
- Start Command: `npm start`
- Health Check Path: `/api/health`
- Persistent Disk mount path: `/var/data`
- один instance

Обов’язкові змінні:

- `NODE_ENV=production`
- `DB_PATH=/var/data/db.json`
- `UPLOAD_DIR=/var/data/uploads`
- `SESSION_SECRET` — довгий випадковий рядок
- `PUBLIC_BASE_URL` — адреса вашого сайту Render

Змінна Mapbox або Google Maps не потрібна.

Існуючий `/var/data/db.json` не перезаписується. Після першого запуску він автоматично доповниться ціною години 120 zł, а старі заявки залишаться на місці.

## Локальний запуск

Потрібен Node.js 20 або новіший.

```bash
npm install
npm start
```

Відкрийте `http://localhost:10000`.

Публічні безкоштовні сервіси Photon і OSRM не потребують ключа, але не мають комерційної гарантії безперервної роботи.
